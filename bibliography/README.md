# DyslexiaFont.org - Bibliography & Research References

## Purpose

This folder contains annotated references that inform the design and development of the DyslexiaFont.org platform. Each reference includes:

1. **Full citation** (APA format)
2. **Key findings** relevant to our platform
3. **How we use it** - specific application in our design decisions
4. **Limitations** - what the study doesn't address (often individual variation)

## Organization

| File | Contents |
|------|----------|
| `core-research.md` | Foundational studies on typography and dyslexia |
| `individual-variation.md` | Research supporting personalized approaches |
| `font-design-studies.md` | Studies evaluating specific dyslexia fonts |
| `doe-methodology.md` | Design of Experiments methodology references |
| `future-exploration.md` | Emerging research and unexplored parameters |

## Citation Format

All citations follow APA 7th edition format for consistency and academic publication readiness.
